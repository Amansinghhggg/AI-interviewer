# AI Interview Platform

> A production-oriented AI recruitment platform built phase by phase.

## Vision

This platform helps companies automate the first screening round using AI interviews while also supporting an Interview Practice mode for candidates.

### Recruitment Mode
Employer → Hiring Campaign → Candidate Interview → Employer Report

### Practice Mode
Candidate → Configure Mock Interview → AI Interview → Instant Feedback

Both modes share the same interview engine.

---

## Development Philosophy

- Build phase by phase.
- Never implement future phases early.
- Keep the project modular.
- Optimize only after features work.
